# Arifa H. homepage demo (Sorix.Co)

One page, static HTML + CSS + vanilla JS. No backend, no tracking, no build step. Pages are `noindex`.

```powershell
cd code
node serve.mjs     # http://localhost:5173
```

## Files
```
index.html            the homepage
css/styles.css        all styles (five colour variables, one --font variable)
css/fonts.css         Manrope, self-hosted (SIL OFL)
js/main.js            reveal, mobile menu, service preselect, booking form, certifications expand
assets/               favicon.svg, fonts/Manrope.woff2, img/arifa-{480,800,1084}.{avif,webp,jpg}
_archive/v1/          the previous multi-page build (not linked, not served by the nav)
```

To switch the font to Instrument Sans, change `--font` and `css/fonts.css`.
