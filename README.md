# Arifa H. homepage demo (Sorix.Co)

One page, static HTML + CSS + vanilla JS. No backend, no tracking, no build step. Pages are `noindex`.

```powershell
cd code
node serve.mjs     # http://localhost:5173
```

## Files
```
index.html           the homepage
css/styles.css       styles (palette in :root, --font-display and --font-sans)
css/fonts.css        Instrument Serif and DM Sans, self-hosted (SIL OFL)
js/main.js           reveal, audience switch, services accordion, booking card, slider, menu
assets/img/          portrait crops (arch, circle, brass badge) and five service photos, AVIF/WebP/JPG
_archive/            v1 (multi-page build) and v2 (first minimal homepage); not linked
```
Service photos are from arifa-images.json (Unsplash licence): IMG-OFFICE-03, -01, IMG-DOC-02, IMG-DOOR-01, IMG-JOURNAL-01.
